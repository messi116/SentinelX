# SentinelX — System Architecture

## 1. Architecture Overview

SentinelX is designed as a modular SOC investigation platform.

The architecture separates telemetry collection, security detection,
event correlation, attack reconstruction, risk assessment, MITRE
mapping, AI-assisted investigation, and analyst visualization.

The system follows an evidence-first architecture in which AI operates
on structured security evidence generated by the underlying security
processing pipeline.
