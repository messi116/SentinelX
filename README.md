# SentinelX

## AI-Powered Autonomous SOC \& Attack Investigation Platform

SentinelX is an advanced Security Operations Center platform designed
to improve security monitoring, threat detection, event correlation,
incident investigation, attack-chain reconstruction, and analyst
decision-making.

## Vision

SentinelX aims to move beyond traditional alert-based SOC monitoring
by correlating security telemetry, identifying behavioral patterns,
reconstructing attack timelines, mapping activity to MITRE ATT\&CK,
calculating contextual risk, and providing evidence-based AI-assisted
investigation.

## Core Components

* Security Event Ingestion
* Detection Engine
* Event Correlation Engine
* Behavioral Analysis
* Risk Scoring
* MITRE ATT\&CK Mapping
* AI Investigation Engine
* Threat Hunting
* Attack Timeline
* SOC Dashboard
* Response Recommendations

## Technology Stack

\### Core Architecture



SentinelX follows an evidence-first security investigation pipeline:



\*\*Security Telemetry → Normalization → Detection → Correlation → Incident → Evidence → Risk Assessment → MITRE ATT\&CK → Investigation → AI Analysis → Response Support\*\*



The initial SOC telemetry environment uses Wazuh for endpoint security monitoring and Suricata for network security monitoring.



\### Development Status



SentinelX is being developed incrementally as an advanced SOC research and engineering project. Future development will implement the telemetry pipeline, detection, correlation, risk assessment, MITRE integration, AI-assisted investigation, threat hunting, dashboard visualization, and evaluation components according to the project roadmap.
